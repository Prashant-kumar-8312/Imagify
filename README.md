# 🎨 AI Image Generator

An AI-powered image generation web application built with the **MERN Stack** that allows users to generate high-quality images from text prompts using **Cloudflare AI**. The application provides secure authentication, image history, credit management, and an intuitive user interface.

## 🚀 Features

- 🔐 User Authentication (JWT)
- 👤 User Registration & Login
- 🖼️ AI Image Generation from Text Prompts
- 📜 Image Generation History
- 💳 Credit-Based Image Generation
- ⬇️ Download Generated Images
- ☁️ Cloudflare AI Integration
- 📱 Responsive UI
- ⚡ Fast REST API with Express.js
- 🗄️ MongoDB Database
- 🔒 Protected Routes & Middleware

## 🛠️ Tech Stack
